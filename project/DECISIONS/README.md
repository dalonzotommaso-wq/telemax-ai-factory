# Decisions

Project-level **Decision Records (DR)** — decisions about _how we work and what we build_ (process,
scope, sequencing). They complement, and do not replace, the **architecture** ADRs that live in the
repository at `docs/architecture/adr/` (which cover technical design).

- One file per decision, using [`template.md`](template.md).
- Decisions are immutable once **Accepted**; a superseding DR is added when a decision changes.
