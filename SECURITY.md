# Security Policy

## Reporting a Vulnerability

Please do not open public issues for security vulnerabilities. Instead, report
them privately to the maintainers so they can be triaged and fixed responsibly.

Provide, where possible: affected package and version, a description of the
issue, reproduction steps, and any suggested remediation. You will receive an
acknowledgement of your report, and will be kept informed as the issue is
investigated and resolved.

## Supported Versions

Until the project reaches a stable `1.0.0`, only the latest published version of
each package receives security fixes.
