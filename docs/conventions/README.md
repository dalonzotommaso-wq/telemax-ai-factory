# Conventions

Engineering conventions for Telemax AI Factory. They exist so the codebase reads
as if written by one careful author, and so that automation (linters,
formatters, CI) can enforce consistency instead of reviewers.

- [naming.md](naming.md) — naming of packages, files, symbols and tokens.
- [coding-style.md](coding-style.md) — TypeScript style and safety rules.
- [branching-strategy.md](branching-strategy.md) — branches and pull requests.
- [commit-convention.md](commit-convention.md) — Conventional Commits.
- [release-workflow.md](release-workflow.md) — versioning and publishing.
