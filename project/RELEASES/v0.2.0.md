# v0.2.0 — Engine stack (Milestone M1→M2 groundwork)

- **Date:** 2026-07-28
- **Milestone:** M1 — AI Gateway core delivered; M2 — Generation Engine groundwork

## Highlights

- The framework's **engine stack** is in place end-to-end as infrastructure:
  Knowledge, Prompt, AI Orchestrator, Workflow and the new **Generator Engine**,
  all building, type-checking, linting and testing green.
- A generic, **target-agnostic Generator Engine** can register generators, run
  declarative generation pipelines and produce artifacts, coordinating the
  Workflow, AI, Prompt and Knowledge engines.
- The **first real generator** ships: `@telemax/generator-wordpress` produces the
  complete WordPress News theme project as versioned, validated artifacts
  (scaffolding only), blueprint-driven and integrating the Workflow, Prompt and
  Knowledge engines. The AI Orchestrator still runs on a local stub.
- **WordPress News Generator v1** (SPRINT-009): the generator now writes a
  complete project to disk via the engine's `FileSystemArtifactWriter`, driven by
  a demo CLI (`pnpm telemax generate wordpress-news`), with per-artifact metadata,
  version and SHA-256 checksum in `.telemax/manifest.json`.

> **Sequencing note.** Delivery follows the SPEC track (SPEC-001…SPEC-006), which
> re-sequences the original milestone plan (it delivered the Knowledge and Prompt
> engines before the AI gateway). The milestone→version map in
> [RELEASE-PLAN.md](RELEASE-PLAN.md) predates this and a full re-baseline is
> pending; this note records the reconciliation.

## Field validation (SPRINT-010)

The WordPress News generator was validated across 5 heterogeneous editorial
profiles (TV news portal, national daily, lifestyle magazine, sports portal,
corporate blog): **5/5 projects generated, 85/85 automated checks passed**,
deterministic output verified (identical modulo timestamp), average quality score
**89.6/100**. One real bug was fixed: WCAG contrast validation wrongly held the
brand `primary` colour to the 4.5:1 normal-text threshold; it now uses the correct
3:1 large-text/UI threshold while body text keeps 4.5:1. See `VALIDATION-REPORT.md`.

## Quality review (RC)

SPRINT-008 ran a full Release Candidate quality review (architecture, code, test,
performance, security, documentation). Findings and fixes:

## Upgrade notes

## Known issues

- The WordPress News generator produces **project scaffolding only** (no plugin,
  no production code); artifacts are produced in memory (a filesystem writer is
  future work).
- No real AI providers yet: the AI Orchestrator uses a local stub, and editorial
  copy uses deterministic prompt rendering.
- Artifact persistence is in-memory by default (filesystem/remote writer is a
  future adapter).
- The `project/` milestone plan vs the SPEC track is not yet re-baselined.
