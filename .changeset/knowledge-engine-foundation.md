"@telemax/knowledge": minor

Add the `@telemax/knowledge` package: the Knowledge Base engine (documents,
metadata, versioning, categories, tags, Markdown/JSON/YAML loaders with prepared
PDF/image loaders, in-memory repository with version history, full-text index with
a prepared embedding index, validation, import/export, a typed event bus and DI
wiring). Depends only on `@telemax/core`.
