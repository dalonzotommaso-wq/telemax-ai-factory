# Gruppo AIR Blog — project overview

Generated by Telemax AI Factory (WordPress News generator v0.1.0),
authored on the generic Generator Engine and coordinated with the Workflow, Prompt
and Knowledge engines.

## What is generated

A complete WordPress News **theme project structure** as artifacts: configuration,
page layouts, structural partials, advertising blocks, widget areas, SEO and
Schema.org components, `robots.txt`, sitemap and manifest configuration, an image
directory layout, naming conventions and this documentation.

## Integrations

- **Workflow Engine** — a prepare workflow computes the build metadata written to
  `.telemax/build-info.json`.
- **Prompt Engine** — renders the site meta description used by the SEO components.
- **Knowledge Engine** — supplies the naming conventions in
  `docs/NAMING-CONVENTIONS.md`.

## Not included (by design)

No plugin, no production WordPress code, no build tooling. Every `.php` file is a
reviewed-before-use scaffold with `TODO` markers.

## Next steps

finalize SEO/Schema output, and add automated theme checks.
